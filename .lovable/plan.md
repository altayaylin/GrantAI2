# План: усиление страницы «Портфолио»

Добавляю 2 новых модуля на `src/routes/_app.portfolio.tsx`. Никаких новых роутов, никакого бэкенда — только UI с захардкоженными моковыми данными в стиле остальной страницы.

## 1. Profile Strength Score (вверху, заменяет/дополняет AI-баннер)

Новый блок-герой, который встанет сразу после хедера и заменит текущий узкий AI-совет. Двухколоночный layout:

**Левая колонка (≈40%)** — большой круговой индикатор:
- Радиальный SVG-прогресс с градиентом `var(--gradient-brand)`
- По центру: `78` крупно + `/100` мельче + подпись «Сила профиля»
- Под ним маленькая подпись «+6 за последние 2 недели» с иконкой тренда

**Правая колонка (≈60%)** — разбивка по 4 категориям:
- Academics — 92
- Extracurriculars — 70
- Essays — 45
- Recommendations — 60

Каждая строка: иконка + название + число + горизонтальный прогресс-бар с градиентом. Цвет бара мягко меняется (зелёный/янтарный/красный) в зависимости от значения.

Снизу блока — Gap Analysis строкой:
> «Чтобы дотянуть до среднего профиля поступившего в **MIT**: +1 research project, +40 SAT EBRW, +1 national award»

С кнопкой «Открыть план действий» (визуальная, без onClick-логики, как остальные кнопки).

Весь блок — один большой rounded-2xl card с тонкой границей и `var(--shadow-soft)`, без яркой заливки (чтобы не конкурировал с цветным AI-баннером ниже).

## 2. Сравнение с целевыми вузами

Новая секция между «Академическими достижениями» и «Внеучебной деятельностью» (или внутри правой колонки с целевыми университетами — обсудим в реализации, лучше первое — нужна ширина).

Заголовок: **«Сравнение с целевыми университетами»** + подзаголовок «Твой профиль vs средний поступивший».

Внутри — сетка карточек по одной на университет (MIT, ETH Zürich, TU Delft из существующего `unis`). Каждая карточка содержит:

- Шапка: название вуза, страна, badge приоритета (Reach/Target/Safety), мини-индикатор «Шанс: 34%» справа
- 4 сравнительные строки (SAT, GPA, Activities, Awards). Для каждой:
  - Label слева (например `SAT`)
  - Двойной горизонтальный бар: тонкий серый — средний поступивший, поверх — синий градиент = твой показатель
  - Справа: `1500 / 1540` (твоё / среднее), цвет цифры зелёный если ≥, янтарный если близко, красный если сильно ниже
- Снизу карточки — короткий вывод одной строкой: «Дотягиваешь по академике, не хватает research» с иконкой

Карточки в `grid grid-cols-1 lg:grid-cols-3 gap-4`, hover-эффект как у остальных (border + shadow).

## Технические детали

- Файл: только `src/routes/_app.portfolio.tsx`
- Новые компоненты внутри файла: `ProfileStrengthCard`, `CategoryBar`, `UniComparisonCard`, `CompareRow`
- Круговой прогресс — inline SVG (без новых зависимостей), 2 наложенных `<circle>` с `stroke-dasharray`
- Моковые данные с реалистичными цифрами для MIT/ETH/TU Delft (средние SAT/GPA)
- Все цвета через существующие токены `var(--gradient-brand)`, `var(--gradient-deep)`, `var(--shadow-soft)`, `border-border`, `text-muted-foreground`. Семантические статусные цвета (emerald/amber/red) — точечно через Tailwind, как уже сделано в `statusMap`
- Сохраняю существующий AI-баннер — он теперь смотрится как «следующее действие» под Strength Score
